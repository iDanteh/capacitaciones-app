El verbo
que vende.

Los productos que ganan son verbos. Zoom. Slack. Stripe. Notion.

Capta también lo es. No describe lo que es: describe lo que hace tu equipo cuando lo usa. Ese cambio de sustantivo a verbo es el que convierte un nombre en una promesa.

"Captar" en español significa asimilar, comprender, retener. Es exactamente lo que pasa cuando alguien aprende algo bien. El nombre de tu producto es tu propuesta de valor en una palabra.

Guía de uso

Modificar es simple.
Mismas reglas, siempre.

Los íconos usan stroke="currentColor" y stroke-width="1.6". Color, tamaño y grosor se ajustan en una línea.

1. Color CSS

El stroke usa currentColor. Cambiá el color del contenedor y el ícono lo hereda — perfecto para hover y dark mode.

/* el ícono toma el color del texto */
.button { color: var(--accent-deep); }
.button:hover { color: white; }

<!-- En HTML -->
<button class="button">
  <img src="icons/sparkle.svg">
</button>

2. Tamaño HTML

Sobreescribí width y height. El viewBox 24×24 escala perfecto a 16, 20, 24, 32, 48px.

<!-- 16px (denso) -->
<svg width="16" height="16" viewBox="0 0 24 24">…

<!-- 32px (hero) -->
<svg width="32" height="32" viewBox="0 0 24 24">…

3. Grosor SVG

Default stroke-width="1.6". Subí a 2 para énfasis, 2.4 para bold, 1.2 para versión ligera.

<svg stroke-width="2"> <!-- énfasis -->
<svg stroke-width="2.4"> <!-- bold -->
<svg stroke-width="1.2"> <!-- ligero -->

4. En React JSX

Importá como componente con un loader SVG, o como url. Para currentColor que funcione, inlinealo.

// Con vite-plugin-svgr o similar
import Sparkle from './icons/sparkle.svg?react';

<Sparkle width={20} color="var(--accent)" />

// O como url (sin currentColor)
<img src="/icons/sparkle.svg" width="20" />

5. Crear un ícono nuevo Plantilla

Para mantener coherencia: 24×24 viewBox, stroke 1.6, round caps/joins, padding interno ~2px, sin fills (excepto play).

<svg xmlns="http://www.w3.org/2000/svg"
  width="24" height="24" viewBox="0 0 24 24"
  fill="none"
  stroke="currentColor"
  stroke-width="1.6"
  stroke-linecap="round"
  stroke-linejoin="round">
  <path d="..." />
</svg>

6. Logo en código SVG

Los logos usan un gradiente del color profundo al suave. Para color sólido, reemplazá url(#m) por el hex que quieras.

<!-- Color sólido -->
<path fill="#1F5C4D" ... />

<!-- Monocromo blanco -->
<path fill="white" ... />
